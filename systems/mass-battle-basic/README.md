# mass-battle-basic

Reference system package (§12) for strategic play: a WHFB/KoW-like ruleset —
move, shoot, melee, saves, wounds, morale/rout, simple supply attrition.

Implemented in Milestone 2 together with the RulesModule loader and SimWorker
(see PLAN.md → M2 → Strategic). Files here follow §12's package layout when
they land: `manifest.json` with a `rules` block plus `rules/index.js`.
Until then this directory intentionally contains only its barrel and this note.
